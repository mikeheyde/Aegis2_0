## Aprendizados do XING LING
- O estudo mais novo, em `2026-06-08.md`, voltou o foco para **Graceful Adaptive Routing (gAR)** em **Huawei CloudEngine** para fabric de IA.
- Para pré-vendas Huawei data center, a lição prática é não vender **gAR** como ECMP "inteligente" genérico: ele depende de **`CE-LIC-GAR`**, hardware **CE16800 com J/J2 cards**, **Packet Event latency visualization**, domínio **sem tunnel**, rotas públicas e entendimento do algoritmo de treinamento.
- Em discovery, as perguntas mais úteis agora são: se o cluster é mesmo de **AI training**, se o domínio usa **overlay/tunnel**, se existe apetite para operar com **PTP + Packet Event**, e se o workload usa **NCCL ring** ou outro algoritmo coletivo.
- O aprendizado mais acionável para Huawei data center é que **gAR** se encaixa melhor como mecanismo de **mitigação gradual de hotspots em AI fabric** do que como promessa universal para qualquer malha L3.
